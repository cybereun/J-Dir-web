02 / BUILT FOR YOUR EVERYDAY

매일 쓰는 도구라서,
작은 것까지.

한글과 PDF도 원본 모양 그대로

실제 앱에서는 HWP·HWPX·PDF를 페이지 단위로 살펴보고, 문서 안에서 내용을 찾을 수 있습니다. 웹 체험에서는 준비된 샘플 문서로 미리보기 흐름을 재현합니다.

압축을 풀기 전, ZIP 내부 확인

실제 앱은 ZIP 안의 파일 목록과 지원 문서·이미지를 보여주며, 전체 또는 선택 항목 압축 풀기를 지원합니다. 웹 체험에서는 샘플 ZIP의 내부 목록과 문서·이미지를 살펴볼 수 있습니다.

작업 공간은 다음에도 그대로

레이아웃, 탭, 정렬, 필터와 테마를 저장하고 다음 실행 때 복원합니다. 자주 쓰는 폴더는 즐겨찾기로 빠르게 찾아가세요.

설치 후 업데이트도 간편하게

새 버전이 나오면 앱에서 업데이트를 확인할 수 있습니다. 이 페이지의 다운로드 버튼도 최신 정식 설치 파일을 제공합니다.
