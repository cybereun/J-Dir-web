# J-Dir Web

J-Dir 홍보 및 다운로드 사이트. Vercel의 정적 사이트 + Node.js 서버 함수로 구성합니다.

## 개발

Node.js 22 이상에서 `npm ci`, `npm run dev`를 실행합니다. 로컬 주소는 `http://127.0.0.1:4173`입니다. 데이터베이스 연결이 필요하면 `node --env-file=.env.local scripts/dev.mjs`를 사용합니다. 테스트는 `npm test`, 정적 빌드는 `npm run build`입니다.

Google Drive 등 가상 드라이브에서 npm 압축 해제가 실패하면 프로젝트를 로컬 NTFS 경로로 복사하여 의존성을 설치하고 개발 서버를 실행하세요.

## 배포

Vercel에 저장소를 연결합니다. Framework는 Other, Build Command는 `npm run build`, Output Directory는 `dist`입니다. `api/*.mjs`는 서버 함수로 배포됩니다. main 브랜치 푸시 시 자동 배포합니다.

## 최신 버전과 다운로드

- `/api/release`: 최신 정식 릴리즈를 조회하고 버전과 일치하는 Windows x64 설치 파일을 선택합니다. 이름 규칙은 `J-Dir_{version}_x64-setup.exe`입니다.
- `/api/download`: 원본 저장소로 리디렉션하지 않고 설치 파일을 서버에서 스트리밍합니다. 응답 헤더 및 JSON에 원본 저장소 주소를 포함하지 않습니다.
- 최신 버전 조회는 서버와 CDN에서 각각 최대 60초 캐시하며, 열린 페이지는 60초마다 갱신합니다. 정상 상황에서 신규 정식 릴리즈는 수 분 이내 반영됩니다. Draft, prerelease, 설치 파일 누락 릴리즈는 제공하지 않습니다.
- 릴리즈 API 실패 시 임의의 옛 버전을 최신으로 표시하지 않으며, 다운로드 오류 시 503 안내를 제공합니다.
- 환경변수 `RELEASE_REPOSITORY`로 원본 저장소를 지정할 수 있습니다. 필요 시 `RELEASE_TOKEN`을 서버 환경변수로만 설정하세요. 브라우저에 토큰을 전달하지 않습니다.

## 방문 / 다운로드 통계

Vercel에 연결한 사이트 전용 Neon 무료 데이터베이스를 사용하며, `DATABASE_URL`은 서버 환경변수로 관리합니다.

- 누적 방문: 한국 시간 기준 동일 브라우저의 랜덤 식별자당 하루 1회. localStorage로 식별자를 보관하고 IP, 이름, 이메일은 통계 테이블에 저장하지 않습니다. 일별 중복 방지 레코드는 2일이 지난 뒤 정리합니다.
- 다운로드: 설치 파일 전송 시작 횟수. 설치 완료, 다운로드 완료, 고유 사용자 수를 뜻하지 않습니다. HEAD 요청은 집계하지 않습니다.
- 누적 숫자는 영구 데이터베이스에 보관되어 함수 재시작·재배포에도 유지됩니다. 원자적 SQL로 동시 증가 및 중복 방문을 처리합니다.
- 통계 장애가 다운로드를 막지 않습니다. 통계 준비 중에는 가짜 숫자 대신 대시와 안내를 표시합니다.
- 가벼운 공개 카운터이며, 봇 차단·정밀 분석 시스템은 아닙니다. 브라우저 저장소 삭제/다른 기기는 별도 방문으로 집계됩니다.

## 체험 화면

실제 앱의 다중 패널, 파일 목록, 우측 미리보기 구성을 가상 자료로 재현했습니다. 1/2/4분할 전환, 샘플 파일 복사, 한글/PDF 페이지 전환, 이미지 확대, 음악·동영상 재생, ZIP 내부 문서·이미지 탐색을 지원합니다.

한글/PDF/ZIP은 웹용 샘플로 재현한 체험이며 실제 파일 파서가 아닙니다. 실제 사용자 파일을 업로드하거나 처리하지 않습니다. 음악, 영상, SVG 이미지는 이 사이트용으로 제작한 오리지널 샘플입니다. `scripts/create-media.py`는 Pillow로 샘플 오디오·프레임을 생성하며, 영상 인코딩에는 FFmpeg를 사용합니다. 생성된 미디어는 저장소에 포함되어 배포 시 Python/FFmpeg가 필요하지 않습니다.

## 노출 범위

공개 화면과 브라우저 JS에는 제작자명, 이메일, 개인 경로, GitHub 주소가 들어 있지 않습니다. 다만 공개 소스 저장소 자체, 앱 설치 파일 내부의 기존 정보까지 숨기는 익명화 기능은 아닙니다. 원본 앱과 설치 파일은 수정하지 않습니다.

`.env*`, `.vercel`, 개발 산출물, 사용하지 않은 Sites 시작 템플릿(`site/`)은 Git 및 배포에서 제외합니다. 비밀값을 커밋하지 마세요.
